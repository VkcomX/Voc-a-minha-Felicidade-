# 💗 SITE PARA O MEU AMOR — V2

Agora o site tem:
- Mensagens/carta em modal
- Contador de relacionamento
- Galeria para fotos
- Linha do tempo
- Motivos pelos quais você ama ela
- Cartas para ocasiões diferentes
- Seção final romântica
- Design responsivo para celular e PC
- Animações e efeitos
- Estrutura pronta para adicionar conteúdo
- SEM senha, como solicitado

## 1. CONTADOR
Abra `script.js` e procure:

const relationshipStart = new Date("2026-01-01T00:00:00");

Troque a data pela data real em que vocês começaram a namorar.
Exemplo:
const relationshipStart = new Date("2025-08-15T00:00:00");

## 2. NOVA MENSAGEM
Dentro de `messages`, copie uma mensagem existente e altere:
title
subtitle
label
icon
text

## 3. LINHA DO TEMPO
Edite a lista `timeline` no `script.js`.

## 4. MOTIVOS
Edite a lista `reasons`.

## 5. MÚSICA
A função já está preparada. Você pode adicionar um arquivo MP3 ao projeto e configurar um player quando tiver a música escolhida.

## 6. FOTOS
Na versão atual, os espaços da galeria são placeholders. Você pode colocar imagens de vocês na pasta do projeto e trocar os placeholders por <img> no HTML.

Abra `index.html` no navegador para testar.
